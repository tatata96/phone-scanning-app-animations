# Phone Scanning App Animations

A responsive, mobile-first feature showcase for a document scanning app, built with React and TypeScript. The project explores animated iPhone scenes for five features:

- Document Scanner
- Sign & Stamp
- Batch Scanning
- Advanced Filters
- Export & Share

## Planned behavior

Feature navigation updates the accompanying text and phone scene. Each scene combines a phone entrance animation with its own sequence of animated elements inside or around the phone. Animations restart whenever the selected feature changes, including when returning to a previously viewed feature.

Layouts will adapt across mobile and desktop, with close attention to visual detail and cross-browser support.

## Status

The React starter is set up. Scene structure and animation behavior are being planned before implementation.

## Development

Built with React, TypeScript, and Vite. Code quality tools include ESLint, Stylelint, and Prettier.

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Run lint and type checks:

```sh
npm run lint
```

Format the code:

```sh
npm run format
```

Create a production build:

```sh
npm run build
```

Preview the production build:

```sh
npm run preview
```
